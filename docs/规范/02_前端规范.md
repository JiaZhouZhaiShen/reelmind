# 02 前端规范

> 对应铁律：R2.1-R2.10
> 作用：React SPA（web/src/）的状态管理、组件结构、代码质量边界。

---

## R2.1 业务状态归 store

**边界**：
- API 返回的数据必须进 Zustand store
- 组件 `useState` 只允许存 UI 状态（输入框值、下拉展开、选中项）

```tsx
// ✅
const pendingCounts = useAIStore(s => s.pendingCounts)
// ❌
const [pendingCounts, setPendingCounts] = useState(null)
useEffect(() => { api.xxx().then(setPendingCounts) }, [])
```

**例外**：纯 UI 临时状态（弹窗开关、Tab 选中）可留在组件。

## R2.2 子组件从 store 读数据

**边界**：子组件优先从 store 读，父组件不向下传业务 props。超过 5 个业务 props 即警告。

```
优先顺序：默认从 store 读 → 测试或复用时 props override
```

## R2.3 组件自包含三态

**边界**：每个组件内部处理 loading / error / empty 三种状态，不依赖父组件。这是空 catch 不会白屏的根本保障。

```tsx
if (loading) return <SkeletonCard />
if (!data) return <div className="text-gray-500">无数据</div>
return <div>...</div>
```

## R2.4 整页 ErrorBoundary

**边界**：每个路由页面外层包 ErrorBoundary。

```tsx
<Route path="/ai" element={
  <ErrorBoundary fallback={<AIPageError />}>
    <AIEnginePage />
  </ErrorBoundary>
} />
```

## R2.5 高频组件加 memo

**边界**：列表项、卡片、侧边栏等高频重渲染组件用 `React.memo` 包裹。**全项目零 React.memo 是性能 bug。**

**优先级**：VideoCard → SearchVideoCard → Sidebar → AIPendingOverview → GPUInfo → AIModelStatus

## R2.6 禁止空 catch

**边界**：每个 catch 必须有用户可见反馈（setError / console + 提示）。

```tsx
// ✅
catch (err) { setError("连接服务器失败，请检查服务状态") }
// ❌
catch {}
```

**例外**：`video.play().catch(() => {})`（浏览器 autoplay 策略）、clipboard API、SSE JSON 解析异常。

**检查**：
```bash
grep -rn "catch\s*()\s*=>\s*{}\|catch\s*{}" web/src/ | grep -v "video\.play\|clipboard\|node_modules"
```

## R2.7 i18n 禁硬编码中文

**边界**：所有用户可见文本走 `t('key')`，禁止在组件/js 中直接写中文字符串。i18n key 放 `web/src/i18n/locales/{zh,en}.json`。

```tsx
// ✅
<ErrorBar message={t('errors.loadFailed')} />
// ❌
<ErrorBar message="无法加载库列表" />
```

**检查**：
```bash
grep -rn '["'"'"'].*[一-鿿].*["'"'"']' web/src/ --include="*.tsx" --include="*.ts" | grep -v "i18n\|locales\|node_modules"
```

## R2.8 无死代码残留

**边界**：源码目录禁止 `.bak` / `.refactor-backup` / `.original` 文件。不使用的页面组件必须在同一改动中删除。备份请用 `scripts/backup.sh` 进 `backups/` 目录，不要留 `.bak` 在源码目录。

**检查**：
```bash
find web/src -name "*.bak" -o -name "*.refactor-backup" -o -name "*.original"
```

## R2.9 TS 严格模式

**边界**：`tsconfig.json` 必须开启 `strict` + `noUnusedLocals` + `noUnusedParameters`。这些开关关闭意味着代码腐化入口大开。

```bash
npx tsc --noEmit   # 类型检查必须零错误（package.json 已补 typecheck 脚本，可用 npm run typecheck）
```

## R2.10 页面组件 ≤1000 行

**边界**：`pages/` 与 `components/` 下 .tsx 文件均不得超过 1000 行。超过即拆分子组件。

> 说明：500 行上限对大型页面过紧，经 2026-09-02 评审调整为 1000 行。仍属硬上限，超限即拆。

**检查**：
```bash
find web/src/pages web/src/components -name "*.tsx" -exec wc -l {} \; | awk '$1 > 1000'
```
