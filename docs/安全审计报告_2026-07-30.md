## 二、严重风险

### 2.1 大量 API 端点完全无鉴权

**影响范围**：以下路由中的所有端点均无 `Depends(get_current_user)` 鉴权依赖，任何未认证用户都可执行全部操作：

| 路由文件 | 暴露端点 | 风险 |
|----------|---------|------|
| `api/assets.py` | 列表/搜索/时间线全端点 | 任意查看所有媒体元数据 |
| `api/assets_detail.py` | CRUD + transcript/segments + AI 触发 | 任意修改/删除/导出媒体 |
| `api/preview.py` | 缩略图/字幕/代理视频/源文件/下载 | 任意下载所有媒体文件 |
| `api/assets_browse.py` | 目录树 + 批量更新/删除/标签 | 任意批量操作 |
| `api/libraries.py` | 库 CRUD + 路径管理 | 任意管理媒体库 |
| `api/tags.py` | 标签 CRUD + 自动标记 | 任意修改标签体系 |
| `api/search.py` | 语义搜索 | 任意搜索所有内容 |
| `api/ai/*` | 全 AI 端点（pipeline/process/models/scan/scan_events 等） | 任意触发 GPU 任务 |
| `api/assets_repair.py` | 全修复端点 | 任意执行修复操作 |

**已鉴权的路径**（无需修改）：`/auth`、`/admin`、`/scan`（顶层 api/scan.py 全部 5 个端点均挂 `require_auth`）、`/system`（scan-settings 部分）。

> ⚠️ 注意：`api/scan.py` 有鉴权，但 `api/ai/scan.py` 和 `api/ai/scan_events.py` 没有，后者属于上方 `api/ai/*` 范围。

#### 修复措施

**方式一：逐路由添加 `Depends(get_current_user)`**（推荐，改动量小）

在每个路由文件的每个 `@router.get/post/patch/delete` 端点函数签名中添加依赖：

```python
# 修改前
@router.get("/items")
async def list_items(session: AsyncSession = Depends(get_session)):
    ...

# 修改后
@router.get("/items")
async def list_items(
    session: AsyncSession = Depends(get_session),
    current_user: dict = Depends(get_current_user),
):
    ...
```

**方式二：主路由层面全局追加依赖**（改动最集中）

在 `server/app/main.py` 中，不鉴权的路由保持原样，需鉴权的路由改成子路由统一注入：

```python
# main.py — 新增受保护的路由前缀
from fastapi import APIRouter
from .auth import get_current_user

# 创建受保护的路由组（所有子路由自动继承鉴权）
protected = APIRouter(dependencies=[Depends(get_current_user)])

# 将需鉴权的路由挂载到 protected 上
protected.include_router(assets.router)
protected.include_router(assets_detail.router)
# ... 其他

# 注册时区分
app.include_router(protected, prefix=settings.API_PREFIX)

# 无需鉴权的路由保持原样
app.include_router(auth.router, prefix=settings.API_PREFIX)  # 登录/注册
```

共 14 处 `detail=str(e)`，分布在 3 个文件：

| 文件 | 行号 | 数量 |
|------|------|------|
| `api/ai/process.py` | 140, 172, 195, 216, 235, 267, 316, 373 | 8 |

| `ai_service/main.py` | 682, 760 | 2 |

#### 修复措施

**方式一：创建统一异常处理工具函数**

```python
# 新建 server/app/utils/errors.py
import logging
import uuid
import traceback

_logger = logging.getLogger(__name__)

def safe_raise(exc: Exception, context: str = "", status_code: int = 500) -> None:
    """记录完整堆栈到日志，仅返回不泄露信息的通用错误给客户端。"""
    error_id = uuid.uuid4().hex[:8]
    _logger.error(
        "[%s] %s failed: %s\n%s",
        error_id, context, exc, traceback.format_exc(),
    )
    from fastapi import HTTPException
    raise HTTPException(
        status_code=status_code,
        detail=f"Internal error (ref: {error_id})",
    )
```

**使用方式**：

```python
# 修改前 (api/ai/process.py:140)
except Exception as e:
    raise HTTPException(status_code=500, detail=str(e))

# 修改后
except Exception as e:
    safe_raise(e, context="start_pipeline", status_code=500)
```

客户端收到：`{"detail": "Internal error (ref: a3f7b2c1)"}`，管理员可通过日志 ID 定位。

**方式二：全局异常处理器自动拦截**

在 `server/app/main.py` 中添加全局异常处理器作为兜底：

```python
# server/app/main.py — app 定义之后添加
import traceback, uuid
from fastapi.responses import JSONResponse

@app.exception_handler(Exception)
async def global_exception_handler(request, exc: Exception):
    error_id = uuid.uuid4().hex[:8]
    _logger.error(
        "[%s] Unhandled exception on %s %s\n%s",
        error_id, request.method, request.url.path,
        traceback.format_exc(),
    )
    return JSONResponse(
        status_code=500,
        content={"detail": f"Internal error (ref: {error_id})"},
    )
```

> 两种方式可同时使用：方式一处理已知 catch 块，方式二兜底未捕获异常。

### 3.4 无 CSRF 保护

所有状态变更（POST/PATCH/DELETE）仅依赖 JWT Bearer Token，无 CSRF Token 或 SameSite Cookie。

#### 修复措施

**方案一：SameSite Cookie + CSRF Token**（标准浏览器防护）

```python
# server/app/auth.py — 登录时设置严格 SameSite Cookie
from fastapi.responses import JSONResponse

@router.post("/auth/login")
async def login(...):
    token = create_access_token(user.id, user.username, user.role)
    response = JSONResponse({"token": token, "user": {...}})

    # 设置 HttpOnly + SameSite=Strict Cookie 作为第二因子
    response.set_cookie(
        key="csrf_token",
        value=secrets.token_hex(32),
        httponly=True,
        secure=True,          # 仅 HTTPS（生产环境）
        samesite="strict",    # 禁止跨站携带
        max_age=60 * 60 * 24 * 7,
    )
    return response
```

```python
# 新建 server/app/api/deps.py — CSRF 验证依赖
from fastapi import Cookie, HTTPException, Request

async def verify_csrf(
    request: Request,
    csrf_token: str | None = Cookie(default=None),
):
    if request.method in ("GET", "HEAD", "OPTIONS"):
        return  # 只读方法跳过

    # 生产环境应存储 csrf_token 做比对，此处简化示例
    if not csrf_token:
        raise HTTPException(status_code=403, detail="CSRF token required")
    # 可选：比对 Cookie 中的 token 与 header 中的
    header_token = request.headers.get("X-CSRF-Token")
    if header_token and not secrets.compare_digest(csrf_token, header_token):
        raise HTTPException(status_code=403, detail="CSRF mismatch")
```

**方案二：仅 API 模式**（SPA + JWT，最简单）

如果你的前端是纯 SPA 且不依赖 Cookie 认证（用 Authorization header），CSRF 风险已大幅降低：

```python
# 确认 Authorization header 仅从 JS 设置（非浏览器自动携带）
# 前端代码确保：
# - Token 存在内存而非 localStorage（防 XSS）
# - 所有请求手动附加 Authorization header
```

```python
    "image/webp": [b"RIFF", b"WEBP"],
}


def verify_file_type(file_path: str | Path) -> str | None:
    """读取文件头魔术字节，返回 MIME 类型，不匹配则返回 None"""
    path = Path(file_path)
    with open(path, "rb") as f:
        header = f.read(16)

    for mime, signatures in ALLOWED_MIME.items():
        for sig in signatures:
            if header.startswith(sig):
                return mime
    return None


# 使用示例
mime = verify_file_type(uploaded_file)
if mime is None:
    raise HTTPException(400, "File type not allowed or corrupted")
```

### 4.4 JWT 使用对称算法 HS256

`server/app/auth.py` 第 39 行：`_JWT_ALGORITHM = "HS256"`

HS256 要求客户端和服务端共享同一密钥，密钥泄露后所有 token 可被伪造。RS256 使用公私钥对，密钥泄露后不影响旧 token 的验证。

#### 修复措施

**对于自托管/单实例部署**：HS256 是可接受的，但应添加注释说明：

```python
# server/app/auth.py
_JWT_ALGORITHM = "HS256"
# 注意：HS256 为对称算法，JWT_SECRET 必须足够长（>=256 bit）且严格保密。
# 若需公私钥分离或防止密钥泄露后的 token 伪造，升级为 RS256。
# 升级步骤：
#   1. openssl genpkey -algorithm RSA -out private.pem -pkeyopt rsa_keygen_bits:2048
#   2. openssl rsa -pubout -in private.pem -out public.pem
#   3. 将 _JWT_ALGORITHM 改为 "RS256"
#   4. jwt.encode(payload, PRIVATE_KEY, algorithm="RS256")
#   5. jwt.decode(token, PUBLIC_KEY, algorithms=["RS256"])
```

**如需升级 RS256**：

```python
# server/app/auth.py — 替换 JWT 部分
from pathlib import Path

_JWT_ALGORITHM = "RS256"
_JWT_PRIVATE_KEY = Path(os.environ.get("JWT_PRIVATE_KEY_PATH", "/run/secrets/jwt_private.pem")).read_text()
_JWT_PUBLIC_KEY = Path(os.environ.get("JWT_PUBLIC_KEY_PATH", "/run/secrets/jwt_public.pem")).read_text()

def create_access_token(user_id: str, username: str, role: str = "user") -> str:
    ...
    return jwt.encode(payload, _JWT_PRIVATE_KEY, algorithm=_JWT_ALGORITHM)

def decode_access_token(token: str) -> dict | None:
    try:
        return jwt.decode(token, _JWT_PUBLIC_KEY, algorithms=[_JWT_ALGORITHM])
    except JWTError:
        return None
```

```python
# server/app/api/preview.py — 添加路径校验函数
from pathlib import Path

def _safe_media_path(relative_path: str | Path, media_root: Path) -> Path:
    """将相对路径解析为绝对路径，并校验在 media_root 子树内。"""
    full = (media_root / relative_path).resolve()
    if not str(full).startswith(str(media_root.resolve())):
        raise ValueError(f"Path traversal detected: {relative_path}")
    if not full.exists():
        raise FileNotFoundError(f"File not found: {relative_path}")
    return full

# 在每个端点中使用
@router.get("/preview/{asset_id}/thumbnail")
async def get_thumbnail(asset_id: str, ...):
    asset = await get_asset(asset_id)
    try:
        file_path = _safe_media_path(asset.thumbnail_path, settings.MEDIA_ROOT)
    except (ValueError, FileNotFoundError) as e:
        raise HTTPException(404, detail="Preview not available")
    return FileResponse(file_path)
```

### 4.10 密码最小长度仅 6 位

`server/app/auth.py` 第 56 行附近。

#### 修复措施

```python
# server/app/api/auth.py — 注册端点中
from pydantic import BaseModel, Field, field_validator

class RegisterRequest(BaseModel):
    username: str = Field(..., min_length=3, max_length=64)
    password: str = Field(..., min_length=12, max_length=128)  # ← 提升到 12

    @field_validator("password")
    @classmethod
    def password_strength(cls, v: str) -> str:
        """密码必须包含大写、小写、数字、特殊字符中至少 3 类"""
        categories = 0
        if any(c.isupper() for c in v):
            categories += 1
        if any(c.islower() for c in v):
            categories += 1
        if any(c.isdigit() for c in v):
            categories += 1
        if any(c in "!@#$%^&*()-_=+[]{}|;:,.<>?/" for c in v):
            categories += 1
        if categories < 3:
            raise ValueError("Password must contain at least 3 of: uppercase, lowercase, digits, special chars")
        return v
```
