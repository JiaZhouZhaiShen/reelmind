# ReelMind 前端 Vite 调试与部署指南

## 一句话

用 Vite 开发服务器在本地跑前端源码，API 走代理到 Docker，实现改代码即时生效。
调试完成后 `npm run build`，Docker 通过 volume 挂载自动读取新文件。

---

## 容器架构

```
reelmind-server  ← 2588  FastAPI 主入口（Web 后端）
reelmind-ai      ← 2589  GPU AI 管线
reelmind-postgres← 5432  数据库
reelmind-redis   ← 6379  缓存
reelmind-worker  ← —     Celery 后台
reelmind-beat    ← —     定时调度
```

## 调用关系

```
浏览器
  ├── (调试) http://127.0.0.1:5173/ai  → Vite → web/src/ 源码
  ├── (生产) http://127.0.0.1:2588/ai   → FastAPI → web/dist/ 构建产物
  └── API  → /api/* → reelmind-server → PG / SQLite / AI
```

## 目录挂载

| 本机目录 | Docker 容器内 | 作用 |
|----------|-------------|------|
| `web/dist` | `/web/dist:ro` | 前端构建产物 |
| `server/` | `/app` | Python 后端（--reload） |
| `server/ai_service/` | `/app` | AI 服务（--reload） |
| `data/reelmind` | `/data/reelmind` | SQLite / 配置 / 日志 |

## Vite 调试

### 启动

```bash
cd web
npx vite --host 127.0.0.1 --port 5173
```

### 配置

`web/vite.config.ts`：
```typescript
server: {
  port: 5173,
  proxy: {
    "/api": {
      target: "http://localhost:2588",  // 代理到 Docker server
      changeOrigin: true,
    },
  },
},
```

### 工作流

```
1. 启动 Vite：npx vite --host 127.0.0.1 --port 5173
2. 浏览器打开 http://127.0.0.1:5173/ai
3. 改 web/src/ 下的 .tsx 文件 → 浏览器热更新
4. 打开 F12 看 Console / Network / Sources
5. 全部调好后 → npm run build 更新到 Docker
```

## Docker 更新

调试完成后：

```bash
cd web
npm run build      # 覆盖 web/dist/
# 浏览器 Ctrl+F5 刷新 http://127.0.0.1:2588/ai 即可
```

**不需要重启 Docker 容器**，因为 `web/dist/` 以 volume 挂载到容器内，文件更新后下次 HTTP 请求自动读新文件。

## 前端页面架构

`/ai` 页面（`AIEngineNew.tsx`）由独立模块组成：

| 模块 | 文件 | 功能 |
|------|------|------|
| AISearchBar | `AISearchBar.tsx` | AI 语义搜索 |
| AIStatsCards | `AIStatsCards.tsx` | 数据统计卡片 |
| AIModelStatus | `AIModelStatus.tsx` | 模型在线状态 |
| AIPipelineSteps | `AIPipelineSteps.tsx` | 管线步骤开关 |
| AIPipelineConfig | `AIPipelineConfig.tsx` | 管线参数配置 |
| ProcessingQueue | `ProcessingQueue.tsx` | 处理队列 |
| AutoRunStatus | `AutoRunStatus.tsx` | 自动运行状态 |
| GPUInfo | `GPUInfo.tsx` | GPU 显存信息 |
| AIModelManage | `AIModelManage.tsx` | 模型加载/卸载 |
| AITokenConfig | `AITokenConfig.tsx` | HuggingFace Token |

每个模块独立自治：自己的 `useState` + `useEffect` 管理数据，不依赖父组件传 props。

## API 端点

前端通过 `web/src/api/client.ts` 的 `api` 对象调用后端，所有 `/api/*` 请求由 FastAPI 处理。

后端 API 定义在 `server/app/api/` 目录下，按功能分文件：
- `ai.py` — AI 统计、管线控制、SQLite 查询
- `assets.py` — 视频资产 CRUD
- `search.py` — 全文+语义混合搜索
- `tags.py` — 标签管理
- `admin.py` — 管理后台

AI 容器 API 定义在 `server/ai_service/main.py`，server 通过 HTTP 代理转发。
